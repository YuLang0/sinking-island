# 잠기는 섬 (Sinking Island)

썰물에 드러나는 길을 따라 섬을 탐험하고, 밀물이 차오르기 전에 항구로 돌아오는 3D 브라우저 게임입니다. 보물을 찾는 것만큼 언제 돌아갈지 결정하는 게 중요합니다.

**[잠기는 섬 플레이하기](https://yulang0.github.io/sinking-island/)**

## 게임 방법

1. **썰물에 출발하세요.** 섬 곳곳의 보물을 줍고, 지도에서 갈 길과 귀환 경로를 확인하세요.
2. **만조 전에 항구로 돌아오세요.** 화면 왼쪽 위에서 남은 시간과 항구까지 걸리는 예상 시간을 볼 수 있습니다.
3. **다음 탐험을 준비하세요.** 항구 사무소에서 보물을 정산하고, 은비의 공방에서 장비를 업그레이드하세요. 모은 유물로 섬의 비밀도 밝혀보세요.

썰물 초반에 잠깐 열리는 **비밀길**에는 날마다 다른 보물이 든 상자가 있습니다. 그날 보물을 하나 이상 줍고 만조까지 **1분 30초 이하**가 남았을 때 항구에 있다면, 상단의 **오늘 탐험 마치기** 버튼으로 하루를 마칠 수 있습니다.
